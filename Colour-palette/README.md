A simple, interactive Color Palette Generator built using HTML, CSS, and JavaScript.

This project generates random color palettes with HEX color codes, allowing users to explore different color combinations and copy their favorite colors to the clipboard.

I built this project to practice JavaScript DOM manipulation, event handling, and responsive CSS layouts while creating something visual and interactive.

## 💡 How It Works

The generator uses JavaScript to create random HEX color codes.

Each color is generated by selecting six random hexadecimal characters from:

```javascript
"0123456789ABCDEF"
```

The generated color is then applied to the background of a color card using JavaScript DOM manipulation.

When the user clicks the Generate Palette button, the application:

1. Generates random HEX color codes.
2. Updates the background of each color card.
3. Updates the displayed HEX values.

The copy functionality uses the Clipboard API to copy the selected color's HEX code.
